Нет роутера? Телефон создаст Wi‑Fi

«Новая сеть» — это не роутер и не интернет из розетки. Её создаёт один телефон (точка доступа / режим модема). В списке Wi‑Fi на ноуте появится имя вроде «iPhone Мария» или «AndroidAP» — к нему и подключаетесь.

  1. Шаг 1 — телефон-раздатчик (ваш или друга, не обязательно игровой):
    Android: Настройки → Сеть → Точка доступа / Hotspot → включить. Запомните имя сети и пароль.
    iPhone: Настройки → Режим модема → «Разрешить другим». Запомните имя и пароль.
  2. Шаг 2 — этот ноут: значок Wi‑Fi → найдите то самое имя с шага 1 → подключитесь паролем с телефона. (Как к обычному Wi‑Fi кафе — только сеть сделал телефон.)
  3. Шаг 3 — гости: на своих телефонах тоже выберите ту же сеть из шага 1.
  4. Шаг 4: вернитесь на эту страницу → «Готово — запустить игру» → создайте стол с QR.

Важно: интернет на раздатчике не обязателен. Нужна только общая «локальная» сеть телефона, чтобы ноут и гости друг друга видели.

Как передать игру гостям

  1. iPhone: QR → «Открыть в браузере».
  2. Android APK: положите updown.apk в dist-host/apk/.

Полный APK ~100 МБ. Гостю: QR → открыть в Chrome (не браузер камеры) → «Скачать APK» → «Всё равно скачать» → подождать. Или сразу «Открыть в браузере» без установки.
