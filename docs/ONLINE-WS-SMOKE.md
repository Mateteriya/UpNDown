# Смоук-чеклист: локальный WS-сервер (до VPS друга)

Прогонять на **2–4 устройствах** в одной Wi‑Fi. Сервер: `npm run server:dev`.  
Фронт: `.env.local` с `VITE_ONLINE_TRANSPORT=ws` и `VITE_WS_URL=ws://IP_ПК:3001`.

## Health

- [ ] `http://localhost:3001/api/health` → `{ "ok": true }`
- [ ] `http://localhost:3001/api/version` → JSON с `build`

## Лобби

- [ ] Создать комнату, код виден
- [ ] Второй игрок входит по коду
- [ ] Имя и аватар видны у всех после смены в профиле
- [ ] Хост может стартовать; после `transfer_host` новый хост тоже стартует

## Партия

- [ ] Заказы и ходы синхронны
- [ ] Взятка / следующая раздача без «залипания»
- [ ] Пауза → «вернуться» без краша сервера

## Чат

- [ ] Сообщения доходят в лобби и в партии
- [ ] «Печатает…» видно на кнопке «Чат» / в шапке
- [ ] Ушко чата **не** показывается; тикер имени **не** крутит текст сообщения

## Сеть / рестарт

- [ ] Закрыть вкладку → открыть снова → `recover` / вход по коду
- [ ] Убить процесс сервера (`Ctrl+C`) → снова `server:dev` → комната из persistence (если была) или честный «не найдена»
- [ ] Auto-reconnect клиента после краткого обрыва сети

## Донаты (не зависит от WS)

- [ ] Меню → «Поддержать» → `#support`
- [ ] ЛК → «Поддержать» / «Поддержать проект»
- [ ] С env-ссылками открываются внешние вкладки; без env — текст «скоро»

## После `wss://` от друга

Те же пункты + HTTPS-фронт (staging) с `VITE_WS_URL=wss://…` (без mixed content).
