## Про «свой Auth = месяцы»

Перегиб. Не «полгода», а **отдельный мини-эпик ~1–3 недели**, если резать этапы:

1. Postgres + users/sessions на VPS  
2. email+password (+ позже OAuth)  
3. перенос профилей / `finish_game` / рейтинга  

Supabase Auth+таблицы мы собрали быстро, потому что **готовая платформа**. Своё — тоже реально, просто **не бесплатно по вниманию** и сейчас **не в топе**: онлайн-стабильность, звук, EN, премиум дают продукту больше, чем замена логина.

Когда дойдём — можно и рейтинг/сезоны/турнирные лестницы сделать «по-взрослому» на своём бэкенде. До тех пор Supabase = identity + persistent data.

## Актуальный порядок работ

### Волна 0 — Стабильный онлайн (сейчас / ближайшие сессии)

Цель: партия на 3–4 с телефона+ПК без микроглюков; сервер у техдира.

1. Дотестировать sync/анимации после правок таймингов (`onlineTimings`, hold раздачи, AI delay).
2. Деплой WS на VPS техдира (`wss://`), healthcheck, prune комнат.
3. Прод-флаг: Preview/LAN = `ws`; решение когда Production тоже на `ws`.
4. Проверить цепочку **конец партии → `finish_game` / Elo / архив** после WS-игры.
5. Мобильный чеклист стола (рука, козырь, auth-callback) — точечная полировка по багам.

**Критерий:** «сыграли вечер с друзьями по ссылке — не стыдно».
