## Актуальный порядок работ

### Волна 0 — Production WS (честный стол) — **P0**

Цель: portable игровой сервер, на котором позже можно держать платящих. **Пакет хосту не отдаём, пока затвор не зелёный.**

1. JWT fail-closed (`WS_AUTH=required`), проекция рук, членская подписка.
2. Конец партии и Elo пишет WS (`finish_game_from_server`), не клиент.
3. Артефакт `server/dist` + `/etc/updown/ws.env` + `/api/ready`. См. [PRODUCTION-WS.md](./PRODUCTION-WS.md).
4. Цепочка конец партии → матч/Elo на staging.
5. Мобильный чеклист стола — точечно по багам.

**Критерий:** нельзя спуфить слот, подсмотреть чужие карты, нарисовать себе очки; процесс поднимается на любом Linux по одному runbook.

После премиума / доната / стабильного прода — ужесточение Auth (не блокирует альфу):

| # | Задача | Зачем |
|---|--------|--------|
| H.1 | Supabase **Secure password change / reauthentication** (сессия старше 24ч → код из письма `{{ .Token }}`) | долгая украденная сессия не сменит пароль без почты |
| H.2 | По желанию: Secure email change ON (подтверждение со старого + нового) | угон сессии не уведёт email тихо |
