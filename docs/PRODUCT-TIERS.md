## Слои

| Слой | Для кого | Деньги | Примечание |
|------|----------|--------|------------|
| **Офлайн vs ИИ** | Все | Free | Без аккаунта ок |
| **Подвал ПК** (режим A: `.cmd` / панель :3927 → :3001; позже режим B: `.exe`) | Хост create **без** аккаунта ок | Free | [HOST-MODES-CANON.md](./HOST-MODES-CANON.md); **не** продаём Wi‑Fi-хост сейчас |
| **Облачный стол** (`game.up2down.online` / лобби сайта) | Create **с аккаунтом** | Free (база) | После зелёного прод-WS |
| **Premium** (`#premium`) | Подписка / entitlement | Платно (позже стор; сейчас тест env/allowlist) | История раздач + премиум-косметика |
| **Хост в кармане** (телефон = комната) | Premium / Special | Платно | Эпик 2; **не обещать** на витрине, пока не играбельно |
| **Утилита Special** (док. «свой хост») | Отдельный SKU | Платно | Позже; не путать с free-подвалом |

Гости вечеринки (QR) могут заходить **без** аккаунта.  
**Создать стол:** облако / лобби сайта — с аккаунтом; панель :3927 (скачанный хост) — без аккаунта.

## Чего не делаем

| Идея | Решение |
|------|---------|
| Деньги за ПК-подвал сейчас | Нет (рано; режет воронку) |
| Лимит «10 столов/день» как монетизация | Нет (для вечеринки бессмысленно; офлайн плохо считается) |
| Репост → +N комнат навсегда | Нет (обходы, спам-UX) |
| Лайк/репост как жёсткий замок | Нет; максимум мягкая просьба «расскажи друзьям» |
| Анонимный create на панели :3927 | Да (локальный дистрибутив) |
| Анонимный create в облачном лобби | Нет — нужен аккаунт |

Мягкий антиабуз по IP на сервере (уже есть лимиты create) — ок, это не продуктовый «тариф».

## APK (когда дойдём)

- Тот же аккаунт / флаг Premium в профиле.  
- Play Billing → проверка на бэке → entitlement.  
- Карман в APK = Premium; подвал с ПК остаётся free+аккаунт (или отдельный Special позже).
