# Панель хозяина (кнопки, без консоли)

## Как открыть

Двойной клик в корне:

**`Открыть-панель-хоста.cmd`**

Или: `npm run host:control` → http://127.0.0.1:3927/

## Сценарий «друзья пришли»

1. Открыли страницу → **сама идёт сборка** игры для телефонов (смотрите лог слева).
2. **Старт** — поднять Wi‑Fi сервер (или включите **Клуб** — автостарт после сборки).
3. Справа: **3 или 4** → **Создать комнату** → код, QR, ссылка, «Поделиться».
4. Гостям — QR → `/join?code=` (лендинг: открыть в браузере или deep link в приложение).
5. После игры — **Стоп**.

**Клубный режим:** до 22 столов, крупные QR, нижняя витрина для стойки.

Отдельная страница `/host` больше не нужна для этого сценария — комната на этой же панели.
