# Сервер игры в вашей Wi‑Fi (ПК)

Программа на компьютере: **создать комнату**, показать **QR** или **код**. Игроки подключаются с телефонов **в той же Wi‑Fi**.

Работает **только в одной сети**. Игра через интернет с другого города — облачный сервер на VPS (не эта утилита).

---

## Для пользователя (установщик с сайта)

Скачайте и установите **«Up&Down — игра в сети»** (Windows). Подробно: [HOST-INSTALLER.md](./HOST-INSTALLER.md).

На ПК нужны только **Windows**, **Wi‑Fi** и **разрешение брандмауэра**. Node.js и терминалы **не нужны**.

---

Полный гайд «когда Rust, как выложить на сайт, что дальше с VPS»: [HOST-LAN-PUBLISH.md](./HOST-LAN-PUBLISH.md).

## Для разработки (пока нет сайта)

| Нужно | Зачем |
|--------|--------|
| **Node.js 18+** | Запуск сервера |
| **npm install** | Один раз в корне репозитория |
| **Wi‑Fi** | ПК и телефоны в одной сети |
| **Брандмауэр** | «Разрешить доступ» для Node при первом запуске |

**Не нужно:** VPN, Supabase, cloudflared, ngrok.

### Быстрый запуск (одна команда)

```powershell
cd D:\Projects\UpNDown
npm run party
```

Соберёт `dist-host` (если нет) → поднимет хост → откроет панель `http://127.0.0.1:3001/host` → **Создать комнату** → QR.

Пересобрать игру с нуля: `npm run party:rebuild`.  
Только панель/сервер (сборка уже есть): `npm run host:app`.

| URL | Что это |
|-----|---------|
| **`http://IP:3001/play/`** | Вечеринка: статика + карты с хоста, **без** `npm run dev` |
| `http://IP:5173` | Только разработка Vite. Без терминала `npm run dev` картинки карт «не скачаны» — так и должно быть |

Если панель «старая»: `npm run host:kill`, затем снова `npm run party`, в браузере **Ctrl+F5**.

**Не запускайте `host:app` / `party` повторно во время живой партии.** Второй старт раньше убивал :3001. Если сервер уже работает, команда только открывает панель.

**Стабильность на раздаче 7–8:** на время партии **закройте Cursor / IDE** (и лишние DevTools). Cursor на том же ПК съедает RAM/CPU → Chrome «залипает». Хост `node` на :3001 лёгкий. Ярлык без IDE: `scripts\party.bat`.

### Нужен ли `:5173`?

**Да — только тебе при правке кода** (HMR). Семье — **никогда**.  
Без процесса Vite нет раздачи ассетов → «пропали карты». Это не чинится «перестройкой Vite в офлайн-сервер».

Домашняя игра: только **`:3001/play/`** (`npm run party`). После пересборки один раз зайди по QR — PWA хоста кэширует карты (соло/офлайн-шелл). **Мультиплеер по Wi‑Fi** всё равно требует, чтобы ПК с хостом был включён.

### Установщик host:desktop (без npm у «мамы»)

Цель: `.exe` → ярлык → панель + `/play/`, пользователю Node не ставить.  
Каркас `host-desktop/` есть; **полный NSIS сейчас не собран** (нужны Rust + VS Build Tools на машине сборки). Это **не** волшебство против лагов от Cursor: IDE на том же ПК всё равно надо закрывать.

```powershell
npm run host:installer:prep
npm run host:desktop:build
```

См. [HOST-DESKTOP.md](./HOST-DESKTOP.md), [HOST-INSTALLER.md](./HOST-INSTALLER.md).

**Аватарки в партии:** на join/meta уходят с фото; на каждом ходе data-URL специально **не** шлём (иначе Wi‑Fi рвёт всех). Клиент хранит уже полученные аватарки; смена имени/фото — через sync слотов.

## На телефонах гостей

- Та же **Wi‑Fi**, что у ПК.
- Открыть **QR** или ссылку (в ВК иногда удобнее **скопировать ссылку** и вставить в Chrome/Safari).
- По ссылке с панели — экран **«Вход в комнату»** и автоподключение (`autojoin=1`).
- Галочка **«Показывать стол в „Зале столов“»** на панели (по умолчанию включена) — стол виден в зале на телефонах.

---

## Запасные порты

В панели — альтернативные ссылки (порты **3002**, **3003**), если основной не открывается.

---

## Сценарий

1. ПК: запуск панели → **Старт** → **Создать** (аккаунт на панели **не обязателен**).
2. Баннер на панели показывает «в аккаунте / не в аккаунте» — для ясности; вход на `/play/` по желанию (история и т.п.).
3. Телефоны: QR → **Войти в комнату** (аккаунт гостю не обязателен).
4. Хост может играть с телефона по той же ссылке.

> Облачное лобби на сайте: create только с аккаунтом. Панель :3927 (дистрибутив): create без аккаунта. См. [PRODUCT-TIERS.md](./PRODUCT-TIERS.md).
