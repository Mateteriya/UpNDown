# DNS: что значит `game.up2down.online` → IP VPS

Простыми словами.

## Зачем

Сейчас сайт **https://up2down.online** открывается у игроков (картинки, меню) — это Vercel.  
Игровой сервер (комнаты, ходы) должен крутиться на **другой машине** — VPS друга.

Мы хотим красивый адрес сокета:

`wss://game.up2down.online`

Это **не новый сайт-меню**. Это «вывеска», которая указывает на VPS:  
«когда браузер стучится в `game.…`, иди на сервер друга».

```text
up2down.online        →  Vercel (как сейчас)     меню / PWA
game.up2down.online   →  IP VPS друга            только игровой WS
up2down.ru            →  SpaceWeb (как сейчас)   зеркало меню
```

Пока DNS не настроен, `game.up2down.online` никуда не ведёт — техдир может поднять процесс, но с твоего домена он не откроется.

---

## Что нужно от друга один раз

Попроси у него **публичный IP** VPS (или скажи: «пришли IP, куда вешать `game.up2down.online`»).

Пример (выдуманный): `203.0.113.40`.

---

## Что сделать тебе (или другу, если у него доступ к DNS)

1. Зайди туда, где управляется домен **`up2down.online`**.  
   Обычно одно из:
   - панель **Vercel** → Project / Team → **Domains** / DNS  
   - **Cloudflare** (если домен делегирован туда)  
   - сайт **регистратора**, где покупала `.online` (Namecheap, REG.ru, Google Domains → Squarespace и т.п.)

2. Найди раздел **DNS** / **DNS Records**.

3. Добавь запись:

| Поле | Значение |
|------|----------|
| Type | **A** |
| Name / Host | **`game`** (получится `game.up2down.online`) |
| Value / Points to | **IP VPS** от друга |
| Proxy (Cloudflare) | лучше **DNS only** (серая тучка), не orange proxy — иначе WebSocket может капризничать |
| TTL | Auto / 300 |

4. Сохрани. Подожди от минут до пары часов (часто 5–15 мин).

5. Проверка с ноута:

```powershell
nslookup game.up2down.online
```

В ответе должен быть **тот же IP**, что дал друг.

После того как техдир поднимет Caddy + сервис:

```powershell
curl.exe https://game.up2down.online/api/health
curl.exe https://game.up2down.online/api/ready
```

---

## Чего не делать

| Не надо | Почему |
|---------|--------|
| Менять запись для голого `up2down.online` | Сломаешь сайт на Vercel |
| Ставить `game` на тот же адрес, что Vercel | Vercel не держит наш Node WS |
| Ждать DNS, чтобы скопировать секреты Supabase | Секреты можно собрать **сейчас**, DNS — когда есть IP |

---

## Если DNS пока страшно / IP ещё нет

Можно временно играть через адрес друга (как `starkey…/updown`) — это запасной путь.  
Канон продукта всё равно: потом переключить на `game.up2down.online`.

Порядок без стресса:

1. Секреты Supabase → техдиру.  
2. Он поднимает WS на VPS, даёт IP + «ready зелёный» на своём домене/IP.  
3. Ты (или он) вешает DNS `game` → этот IP.  
4. Он дописывает Caddy на `game.up2down.online`.  
5. Ты включаешь фронт на `VITE_WS_URL=wss://game.up2down.online`.
