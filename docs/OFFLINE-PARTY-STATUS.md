## Эпик 1 — как гость получает игру

1. Та же Wi‑Fi (hotspot/роутер), что у ПК-хоста.  
2. QR → `/join`.  
3. **Браузер** — сразу «Вход в комнату» (клиент с хоста).  
4. Или **Скачать APK** (если хост положил файл) → Установить → снова QR / «У меня уже есть».

Хосту-разработчику: `npm run party:apk` или Android Studio → файл в раздаче. Гостю вечеринки путь `dist-host` знать не нужно.

## Полный офлайн — чеклист клиента

- Локальный профиль + офлайн vs ИИ без сети: да (boot не ждёт облако).  
- LAN-party `/play/` без Supabase: да (transport override).  
- Облачный рейтинг/история без сети: недоступны (ожидаемо) → локальные данные на устройстве.  
- Онлайн-кнопка без сети: не создаёт «настоящий» интернет-стол (нужен сервер/Realtime).
