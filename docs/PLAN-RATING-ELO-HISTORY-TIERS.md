# План: Рейтинг (ELO) + гейты истории free/premium

Зафиксировано по ответам владельца (2026-07-22). Турнирный топ и сезоны — заложить, не строить UI сейчас.

## A. Рейтинг (таблица лидеров)

### Правила
- Только **онлайн rated** (`is_rated = true`, не offline, не interrupted).
- **ELO-лайт:** старт 1000; после партии 1-е место = win, иначе loss (K≈24 MVP).
- Вторично в строке: партии, победы, win%.
- **Турниры** — отдельный топ позже (заложить `ladder_kind` / scope в схеме).
- **Сезон** — отложить UI; в таблице рейтингов поле `season_id` nullable (`null` = «все время»).

### UI
- Пункт меню **«Рейтинг»** — на мобилке **только внизу**, под «Поддержать проект».
- Кабинет: блок статистики → **«Моя статистика»** (не «Ваш рейтинг»).
- Страница/экран: топ-50 + «Вы: #N · ELO».
- Модалки KPI остаются короткими входами в кабинет / рейтинг.

### Данные
- Таблица `player_ratings` (или расширение `profiles`): `user_id`, `elo`, `games`, `wins`, `season_id`, `ladder_kind` (`open` | позже `tournament`), `updated_at`.
- Обновление в RPC `finish_game` (server-side) после записи матча — один источник правды.
- Клиент: `getLeaderboard()`, `getMyRatingRank()`.

## B. История: free vs premium (мягкий гейт)

### Запись
- Полный `deal_history` пишем **как сейчас** (не режем на insert).

### Чтение (UI)
- **Free:** лента + итог + соперники; в детали — **полные последние 3 раздачи**; остальные раздачи — **лёгкий минимум** (номер раздачи + очки по слотам, без bids/takens или только points).
- **Premium:** все раздачи полностью (когда подписка появится; до этого флаг `VITE_PREMIUM_HISTORY` / stub «скоро»).
- Пока подписки нет: UI-копирайт «Полный разбор раздач — в подписке (скоро)»; free-лимит 3 уже работает.

### Retention (облако, free)
- **90 дней:** у free старше 90д — `deal_history` сжать до lightweight summary (points-only / dealCount+scores), не удалять матч.
- Premium retention — позже (дольше или без сжатия).
- Job: SQL-функция + cron/ручной скрипт `APPLY` или scheduled edge (сначала скрипт + док).

### Локально
- IndexedDB без изменения ценности; при желании тот же лимит 3 в UI для гостя/free-отображения облака.

## C. Вне скоупа этой волны
- Реальный биллинг подписки.
- Сезонный UI / турнирный ladder.
- Фикс тормозов Supabase Realtime (отдельный трек WS).
- Веса мест 2/3/4 в ELO (после MVP).

## D. Порядок работ
1. Миграция `player_ratings` + апдейт `finish_game` (ELO).
2. Клиент API + экран «Рейтинг» + кнопка под Support (mobile).
3. Rename «Моя статистика» в кабинете / копирайт.
4. UI-гейт раздач (3 полных / остальные light) + stub premium.
5. Retention script 90д + доки.
6. Коммит на main/staging по запросу (пуш — владелец).
