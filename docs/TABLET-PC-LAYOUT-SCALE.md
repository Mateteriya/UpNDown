# Планшеты / ПК: раскладка стола и масштаб карт (аудит)

Дата: 2026-07-30.  
Связано с: `src/ui/GameTable.tsx`, `src/game/pcHandScale.ts`, `docs/PC-CARDS-PROTECT-MOBILE.md`.

## Вердикт

**Режим 110% на 4 игроках — калибровка под ПК (ширина ≥1025px).**  
Наложения «везде исключены» — **нет**. Защита есть, но **разная по веткам**; единой проверки «не пересеклись ли рука и сукно» нет.

На обычных планшетах ≤1024px **карты руки не увеличиваются до 110%**.  
Риск тесноты / наследия boost — у **широких планшетов (≥1025)** и у **гибридной** зоны (ПК-оболочка + компактные карты).

---

## Два независимых флага (не путать)

| Флаг | Media Query | Что включает |
|------|-------------|--------------|
| `isMobileOrTablet` | `max-width: 1024px` | Компактные карты руки/взятки, сетка 2×2, панель Юга без шестерёнки масштаба |
| `isMobile` (`viewport-mobile`) | `max-width: 600px` **или** `(max-width: 1024px) and (max-height: 560px)` | Мобильный DOM, short-VH, **полный сброс** PC-scale (`pcScaleBoost = 0`) |

Код: `GameTable.tsx` — `useIsMobileOrTablet`, `MOBILE_VIEWPORT_MQ`, `MOBILE_LANDSCAPE_MQ`.

**Важно:** документы/AGENTS часто пишут «≤1024 = мобилка». По факту класс `viewport-mobile` вешается только при `isMobile` (≤600 или низкий landscape). Высокий планшет 768×1024 — **не** `viewport-mobile`.

---

## Три класса устройств

### A. Телефон / низкий landscape (`isMobile`)

- Раскладка: мобильный DOM + short-VH / landscape-тюнинг.
- PC scale **выключен** (даже если в localStorage лежит 110%).
- Наложения: отдельные мобильные защиты; **не** связаны с 4p/110%.

### B. Гибрид: планшет ≤1024, высота >560 (`!isMobile && isMobileOrTablet`)

Примеры: iPad 768×1024, iPad landscape 1024×768, iPad Pro portrait ~834×1194.

| Слой | Поведение |
|------|-----------|
| DOM стола | **ПК-оболочка** (fixed Юг, spacer, боковые слоты) |
| Карты руки / взятки | **Компакт планшета**, без ×1.10 |
| Шестерёнка масштаба | **Нет** (только в `!isMobileOrTablet` панели) |
| CSS | `@media (max-width: 1024px)`: сукно `min(320px, 25vh)`, `--game-table-up-offset: 90px`, `--game-player-area-height: 300px` |
| Если в LS boost > 0 | Может сжаться **сукно** и сдвинуться бока (`pcFeltScaleMul`, `pcSidePushPx`) — **без UI**, чтобы это снять |

### C. Полный ПК (`!isMobileOrTablet`, ширина ≥1025)

Примеры: монитор 1440×900; **iPad Pro 11" landscape ~1194×834**.

- Шестерёнка есть; 4p max **110%**.
- Рука: `adaptiveBase × 1.10 × 0.98` (компакт 4p).
- Сукно чуть сжимается (~−4.5%); стол **не** поднимается; страница **не** растёт по высоте.
- Короткий экран: `@media (max-height: 1000px)` / mid-width — ужимает зазоры Юга и высоту сукна (`min(420px, 28vh)`).

## Что защищает 4p/110% на ПК (и чего нет)

**Есть:**
- потолок boost 10% на 4p;
- сжатие сукна;
- компакт руки ×0.98;
- уменьшение зазора рука↔панель (−12px);
- CSS short-height для не-mobile;
- на торгах clamp Юга `46dvh` (`.game-pc-user-layer`).

**Нет / пробелы:**
1. **Нет детекта коллизии** рука↔сукно и автоуменьшения.
2. **Два гейта:** scale-state на `!isMobile`, размер руки на `!isMobileOrTablet` → на гибриде boost из LS может менять сукно/бока без увеличения руки и без шестерёнки.
3. **Нет лимита по высоте** для 110% (разрешено на 700–834px full-PC).
4. **localStorage** `updown_pc_hand_scale_boost` общий на origin → широкий планшет / тот же браузер наследует 110% с десктопа.
5. AGENTS / `PC-CARDS-PROTECT-MOBILE.md` упрощают breakpoint и **не описывают гибрид**.

## localStorage

Ключ: `updown_pc_hand_scale_boost` (`pcHandScale.ts`).

| Устройство | Наследует значение? | Визуальный эффект |
|------------|---------------------|-------------------|
| A mobile | читается, но boost принудительно 0 | нет |
| B гибрид | да | частично: сукно/бока; рука без 110%; шестерёнки нет |
| C полный ПК | да | полный 110% |

## QA-чеклист

1. ПК 4p: 100% и 110% — зазор стол↔рука, панель, без скролла страницы.
2. DevTools **768×1024**: нет шестерёнки; рука не ×1.10; ПК-shell.
3. **1024×768**: то же; оценить тесноту Юга vs сукно.
4. **≥1025×~834** (Pro landscape): как ПК; проверить 110% на низкой высоте.
5. На ПК выставить 110% → тот же origin на гибриде: сукно не должно «само» уехать неожиданно (сейчас может).
6. Телефон landscape ≤560h: `viewport-mobile`, без PC-scale.

## Правило правок

- Карты «только ПК» → `!isMobileOrTablet` **и/или** `@media (min-width: 1025px)`.
- Оболочка стола / fixed Юг → смотреть `!isMobile` (гибрид тоже).
- Не считать, что «≤1024 ⇒ нет PC-scale shell».
