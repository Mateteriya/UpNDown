# Канон: как устроен «свой сервер» (2026-10-31)

Один документ вместо путаницы `host:app` / `.cmd` / Tauri / `.exe` / карман / облако.  
Приоритет работ: [PLAN-DALEE.md](./PLAN-DALEE.md). Очередь эпиков: [VISION-QUEUE.md](./VISION-QUEUE.md). Деньги: [PRODUCT-TIERS.md](./PRODUCT-TIERS.md).

---

## Одна фраза

**Вечеринка по Wi‑Fi = сервер на чьём‑то ПК в той же сети.**  
Гости открывают браузер (или APK) → `http://IP:3001/play/`.  
**Это не облако** и **не** «игра-exe как Steam».

---

## Три режима (не путать)

| # | Название | Где крутится сервер | Как хост запускает | Кто может | Статус | Деньги |
|---|----------|---------------------|--------------------|-----------|--------|--------|
| **A** | **Подвал · разработчик** | Твой ПК | `Открыть-панель-хоста.cmd` → панель **:3927** → игровой сервер **:3001** | Ты сейчас | ✅ так и играете | Free |
| **B** | **Подвал · установщик** | ПК любого человека | Скачал **`.exe`** (Tauri-оболочка) → ярлык → та же панель+сервер | Друзья без Node/терминала | 🔲 каркас есть; нужен Rust для сборки NSIS | Free (позже опц. SKU Special) |
| **C** | **Хост в кармане** | Телефон хоста | WebRTC, без ПК | Premium | 🔲 скаффолд, не играбельно | Платно |
| **D** | **Облачный стол** | VPS (`game.up2down.online`) | Сайт / лобби | Все с аккаунтом | 🔲 ждём техдира | Free база |

**A и B — одна и та же идея** (ПК = Wi‑Fi-хост). Разница только в упаковке:

- **A:** у тебя уже есть репозиторий + Node → `.cmd`.
- **B:** у соседа нет Node → ставит `.exe`, внутри тот же сервер + страница `/play/`.

## Что такое Tauri здесь

| | Да | Нет |
|--|----|-----|
| **Tauri `host-desktop`** | Оболочка Windows: окно панели + вшитый Node-сервер + `dist-host` | — |
| **Tauri «игра как exe»** | — | **Не делаем.** Карточный стол = браузер / PWA / APK |

Ты не запуталась: **через Tauri собирали именно установщик хоста**, не десктоп-клиент партии.

## Как тебе играть сегодня (не меняй привычку)

1. Двойной клик **`Открыть-панель-хоста.cmd`**.
2. Панель `http://127.0.0.1:3927/` → создать комнату / клуб.
3. Семья: QR / ссылка / **Зал столов** → **`http://IP:3001/play/`**.
4. На партию **закрой Cursor**.
5. **Не** давай семье `:5173` (это только Vite в IDE).

Запасные ярлыки (не обязательны): `npm run party`, `scripts/party.bat`, `npm run host:app` — тоже поднимают `:3001`, иногда без UI на :3927.

После обновления кода: в панели **«Пересобрать»** (или `npm run party:rebuild`), чтобы телефоны получили свежие карты в PWA-кэш.

## Когда будет `.exe` — у «любого» будет свой сервер?

**Да, в смысле подвала Wi‑Fi:** скачал установщик → на **своём** Windows-ПК запустил → в своей квартире/кафе создал комнаты → гости по QR в той же Wi‑Fi.

**Нет, в смысле «личный VPS в интернете»:** `.exe` не заменяет облачный `game.up2down.online`. Из другого города без общего Wi‑Fi нужна волна **D** (техдир).

**Нет, в смысле «сервер в кармане без ПК»:** это режим **C** (ещё не готов).

---

## Офлайн vs ИИ с картинками

1. Пока хост `:3001` включён, зайди с телефона на `/play/` (лучше «на экран Домой»).
2. PWA с хоста кэширует карты/шелл.
3. Потом можно открыть офлайн vs ИИ без Vite.
4. Партия втроём по Wi‑Fi без включённого ПК-хоста **невозможна** (режимы A/B).

## Когда собирать `.exe` (режим B)

По [HOST-LAN-PUBLISH.md](./HOST-LAN-PUBLISH.md): когда есть страница «Скачать» на сайте и готовность обновлять установщик.  
**Сейчас для твоей семьи `.exe` не блокер** — хватает режима A.

Сборка на машине с:

- Node 18+
- Rust (rustup)
- VS Build Tools (C++)

```powershell
npm run host:installer:prep
npm run host:desktop:build
```

→ `host-desktop\src-tauri\target\release\bundle\nsis\*-setup.exe`

## Порядок приоритетов (единый)

| Сейчас | Что | Зачем |
|--------|-----|--------|
| ✅ | Режим A (`.cmd` + :3001) | Домашние вечеринки |
| ⏳ | Прод-WS (режим D) | Игра из разных сетей |
| 🔲 | Режим B (`.exe`) | Отдать подвал людям без Node |
| 🔲 | Режим C (карман) | Вечеринка без ноутбука, платно |

Не делаем параллельно «ещё один способ запустить то же самое», пока A стабилен.
