# Локальная разработка и вечеринка: URL без путаницы

Один проект Supabase на всех. Путаница была из‑за **трёх разных «входов»** и одного поля **Site URL**.

---

## Что открывать тебе (коротко)

| Твоя задача | URL | Нужен ли сервер `:3001` |
|-------------|-----|-------------------------|
| **Код, UI, Google у себя на ПК** | `http://localhost:5173/` или `http://ВАШ_IP:5173/` (`npm run dev` / `dev:host`) | **Нет** |
| **Вечеринка: телефоны по Wi‑Fi / QR** | `http://ВАШ_IP:3001/play/` | **Да** — `host:app` / панель хоста (раздаёт `dist-host`) |

`:3001` — это **не** «вторая Vite». Это Node-сервер вечеринки. Если он не запущен, `/play/` долго пустой или `ERR_CONNECTION…`, а Google падает на `auth-callback.html` (в HAR — status **0**, два таймаута ~2 с).

**Не смешивать вкладки:** вошла с `:5173` → играй и логинься только там. Вечеринка — только `:3001/play/`.

## Карта портов

| Что | URL | Когда |
|-----|-----|--------|
| **Обычная работа (твой канон)** | `http://localhost:5173/` | Почти всегда. Google тоже отсюда. |
| Dev с телефона в той же Wi‑Fi | `http://ВАШ_IP:5173/` | `npm run dev:host` |
| **Вечеринка / QR** | `http://ВАШ_IP:3001/play/` | Панель хоста → Старт. Гости только сюда. |
| Панель хоста | `http://127.0.0.1:3927/` | Только на ПК организатора |
| Прод | `https://up2down.online` | Сайт (иногда VPN) |

## Supabase → Authentication → URL Configuration

### Site URL (одно поле!)

Это **запасной** адрес, если Redirect URL не подошёл. От него зависит, куда вас выбросит Google.

| Режим | Site URL | Комментарий |
|-------|----------|-------------|
| **Вечеринка сегодня** | `http://ВАШ_IP:3001/play/` | Без `?code=`, без `#online`, без `auth-callback`. Именно так вы уже починили вход. |
| **Обычный день / прод** | `https://up2down.online` | Верните после вечеринки |

Панель хоста (Клуб · APK · журнал) показывает готовые строки и кнопки «Копировать».

### Redirect URLs (список — можно много)

Полный канон (подставьте IP):

```
https://up2down.online/auth-callback.html
https://up2down.online/**
http://localhost:5173/auth-callback.html
http://127.0.0.1:5173/auth-callback.html
http://ВАШ_IP:5173/auth-callback.html
http://192.168.*.*:5173/**
http://ВАШ_IP:3001/play/auth-callback.html
http://192.168.*.*:3001/**
http://localhost:3001/play/auth-callback.html
updown://auth-callback
```

Для **ежедневного** Google с Vite достаточно строк на **`:5173`**. Строки `:3001` — только если реально поднимаешь вечеринку.

Яндекс / VK: [AUTH-YANDEX-VK-MAIL.md](./AUTH-YANDEX-VK-MAIL.md) — их Redirect URI = callback **Supabase**, не эти строки.

**Не Redirect URL игры:** голый `http://…:3001`, `?code=…`, `#online`, join-ссылка.

## Почему вас кидало на up2down.online

1. Site URL был `https://up2down.online`.
2. Локальный `http://IP:3001/play/auth-callback.html` **не** был (или был с ошибкой) в Redirect URLs.
3. Supabase подставлял Site URL → браузер открывал сайт → часто нужен VPN.

Лечение на вечер: Site URL = `http://IP:3001/play/` **или** точный Redirect URL на auth-callback. Клиент **больше не пытается** мостить через прод.

## Чеклист вечеринки с Google + рейтинг

1. Панель хоста → **Старт**.
2. Раскройте **Клуб · APK · журнал** → блок **Google + рейтинг** → скопируйте Redirect URL и Site URL.
3. Вставьте в Supabase → Save.
4. Гости только по QR / `http://IP:3001/play/` (или join).
5. Google → возврат в `/play/` → комната → после партии ELO в том же аккаунте.
6. После вечеринки: Site URL снова `https://up2down.online`.

## Dev без вечеринки

```bash
npm run dev
```

Откройте `http://localhost:5173`. В Redirect URLs — localhost:5173/auth-callback.html. Site URL может оставаться продом, если localhost в Redirect URLs.

Ключи: `.env.local` с `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (те же, что на проде).

### `flow_state_already_used` / «State has already been used»

Частые причины по HAR:

1. **Старт и возврат на разных портах** (`:5173` ↔ `:3001`) — PKCE в sessionStorage не совпадает.
2. **`:3001` не слушает** — callback `…/play/auth-callback.html?code=` в HAR со **status 0** (соединение оборвалось), браузер дергает URL дважды → state сгорает.

| Делать | Не делать |
|--------|-----------|
| Для себя: Google с **`:5173`**, Redirect = `…:5173/auth-callback.html` | Логиниться на мёртвом `:3001` без `host:app` |
| Вечеринка: сначала поднять хост, потом Google с **`:3001/play/`** | Смешивать вкладки 5173 и 3001 в одном входе |
| Одна вкладка; после ошибки — новый «войти» | F5 по старому `?code=` |
