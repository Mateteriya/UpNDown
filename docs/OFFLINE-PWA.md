# Офлайн-орб на главной

После деплоя у пользователей (в т.ч. со старым ярлыком) на главной **прилетает** глиф ↓ справа внизу.

1. Тап по глифу → раскрывается капсула.
2. **Скачать игру для офлайна** — пакет картинок (карты, ИИ, фоны).
3. **Добавить ярлык** — системный install (Android/Chrome) или подсказка для iOS.

## Важно

- Скачивание пакета работает только в **HTTPS / ярлык** (не `http://192.168…`).
- Проверка без полного прод-push: preview-деплой на HTTPS (Vercel preview) или туннель (cloudflared / ngrok) на локалку.

Автозагрузки пакета при открытии меню нет — только действие в капсуле.
