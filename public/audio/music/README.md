# Music (лаб)

`table_bed.wav` — процедурная брейкбит/IDM-петля (168 BPM, 4 такта), пересборка: `npm run audio:gen-music`.

В партии не играет. В лабе (`/audio-sfx-lab`) кнопка **Бит** + слайдеры **Бас / Перкуссия / Industrial / BPM** — петля собирается в браузере (`renderBeat.ts`). Если бит включён, он подмешивается в сохранённый WAV.
